# IBM Plex fonts

These unmodified Latin WOFF2 files were downloaded from Google Fonts on October 22, 2026.
IBM Plex Sans is a variable font (the site uses weights 400–600); IBM Plex Mono uses static weights 400 and 500.

They are loaded with `next/font/local` so builds do not depend on Google Fonts network responses or URL parsing.
Keep the accompanying SIL Open Font License files with these assets.
